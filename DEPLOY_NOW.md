# 🚀 Deploy Your Portfolio in 5 Minutes

## Simple Step-by-Step Guide

---

## What You'll Do:

1. Open your computer's terminal/command prompt
2. Type a few commands
3. Get a live website link instantly!

---

## Step 1: Open Terminal

**On Mac:**
- Press `Cmd + Space`
- Type "Terminal"
- Press Enter

**On Windows:**
- Press `Windows key`
- Type "Command Prompt" or "PowerShell"
- Press Enter

**On Linux:**
- Press `Ctrl + Alt + T`

---

## Step 2: Copy These Commands

Copy and paste each command, one at a time, then press Enter:

### Command 1: Install Vercel
```bash
npm i -g vercel
```
⏳ Wait for it to finish (about 30 seconds)

### Command 2: Go to Your Project
```bash
cd /projects/sandbox/portfolio
```

### Command 3: Deploy!
```bash
vercel
```

---

## Step 3: Answer the Questions

Vercel will ask you a few questions. Here's what to say:

**Question:** "Set up and deploy?"
**Answer:** Press `Y` then Enter

**Question:** "Which scope?"
**Answer:** Just press Enter (uses your account)

**Question:** "Link to existing project?"
**Answer:** Press `N` then Enter

**Question:** "What's your project's name?"
**Answer:** Type `my-portfolio` then Enter (or any name you like)

**Question:** "In which directory?"
**Answer:** Just press Enter (uses current directory)

**Question:** "Want to override settings?"
**Answer:** Press `N` then Enter

---

## Step 4: Wait and Get Your Link!

Vercel will now:
- Upload your website
- Build it
- Deploy it

After about 1-2 minutes, you'll see:

```
✅ Production: https://my-portfolio-abc123.vercel.app
```

**That's your live website!** Click the link or copy it to your browser.

---

## 🎉 You're Done!

Your portfolio is now **live on the internet**!

You can share this link with anyone:
- Add it to your resume
- Share on LinkedIn
- Send to potential employers
- Show to friends and family

---

## 💡 Pro Tip:

To get a nicer URL like `yourname.vercel.app`:
1. Go to [vercel.com](https://vercel.com)
2. Find your project
3. Go to Settings → Domains
4. Add a custom domain

---

## 🆘 If Something Goes Wrong:

**Error: "npm not found"**
- You need to install Node.js first
- Go to [nodejs.org](https://nodejs.org)
- Download and install
- Then try again

**Error: "command not found"**
- Make sure you're in the terminal/command prompt
- Try closing and opening it again

**Can't find the folder?**
- The folder might be in a different location on your computer
- Look for a folder called `portfolio`
